# Getting started

ScoreMatter is currently installed from source. The M0 path uses deterministic
fixture audio so you can inspect its contracts and evidence flow without a
music model, GPU, or network service.

!!! warning "M0 is not AI music generation"
    The current commands prove schemas, content-addressed storage, receipts,
    and replay integrity. They do not prove musical or release quality.

## Requirements

- Python 3.10 or newer
- Git
- Windows PowerShell or a POSIX-compatible shell

## Install from source

=== "Windows PowerShell"

    ```powershell
    git clone https://github.com/andyandymike/score-matter.git
    cd score-matter
    python -m venv .venv
    .venv\Scripts\python -m pip install --disable-pip-version-check -e .
    .venv\Scripts\score-matter --help
    ```

=== "macOS / Linux"

    ```bash
    git clone https://github.com/andyandymike/score-matter.git
    cd score-matter
    python -m venv .venv
    .venv/bin/python -m pip install --disable-pip-version-check -e .
    .venv/bin/score-matter --help
    ```

## Execute the deterministic demo

Create a tiny reviewed bundle and execute it through the built-in mock
provider:

=== "Windows PowerShell"

    ```powershell
    .venv\Scripts\score-matter demo init .local/demo --provider mock
    .venv\Scripts\score-matter mock execute --bundle .local/demo --store .local
    ```

=== "macOS / Linux"

    ```bash
    .venv/bin/score-matter demo init .local/demo --provider mock
    .venv/bin/score-matter mock execute --bundle .local/demo --store .local
    ```

The execute command prints the exact run-receipt path. Everything generated by
this demo remains under the ignored `.local/` directory.

## Verify the receipt

Replay the recorded artifact without regenerating audio:

=== "Windows PowerShell"

    ```powershell
    .venv\Scripts\score-matter replay verify `
      .local/runs/<run-id>/run-receipt.json --store .local
    ```

=== "macOS / Linux"

    ```bash
    .venv/bin/score-matter replay verify \
      .local/runs/<run-id>/run-receipt.json --store .local
    ```

Replay proves that the recorded bytes still match their receipt. It does not
re-run a provider or approve the artifact.
